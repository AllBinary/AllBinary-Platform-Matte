                             AllBinary Platform Matte

What is it?

This repository contains code generated by the AllBinary Platform for support in Matte.  
This repo is used to allow developers to skip the Matte code generation step.

What are some example games with this Matte code?

https://allbinary.itch.io (The downloads with "-matte" in the filename are Matte only builds. Currently that only includes nothing. Also the Matte builds are not available on Google Play or other stores.)
